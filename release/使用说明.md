# StatsOSD

<img src="assets/icon.png" width="88" alt="StatsOSD icon">

**版本：v1.3.0** ｜ [GitHub 发布页](https://github.com/Alooshy0827/StatsOSD/releases/latest) ｜ Windows 10/11 x64 ｜ [许可：专有软件](LICENSE)

透明置顶、鼠标穿透的硬件监控小面板，常驻屏幕角落，实时显示 CPU / GPU / 内存的温度、功耗、负载、频率等（类似微星小飞机的监控叠加层）。

## 功能

- **13 项可选指标**：CPU 温度/功耗/占用/频率 · GPU 温度/功耗/占用/热点/频率/显存/风扇 · 内存 已用/总量 GB
- **硬件配色**：Intel 蓝 / AMD 橙红 / NVIDIA 绿；色块包住该硬件的全部信息，块内显示型号与内存代数频率（如 `DDR5 5600`）
- **三种布局**：迷你 / 标准 / 详细，列宽随数值自适应，永不重叠
- **字体**：四档字号 + 实心描边（默认开启，背景全透明也清晰）
- **温度分级着色**：CPU 80–89° 橙 / ≥90° 红；GPU 75–82° 橙 / ≥83° 红
- **不打扰**：鼠标穿透、强制置顶、四角或自由拖动、色块不透明度 0–100%
- **开机自启**：管理员模式下创建计划任务，登录即启动且免 UAC 弹窗

> 首次启动时，监控数值显示在任务栏。勾选「显示为悬浮窗」后，桌面面板会出现在右下角，使用迷你布局。两处都使用大号 Consolas 字体（120%）、文字描边和 50% 不透明度的底色。

## 运行

1. 打开程序目录，双击 `StatsOSD.exe`。下载压缩包后请先完整解压。
2. 需要 **.NET 8 桌面运行时**（[下载](https://dotnet.microsoft.com/download/dotnet/8.0)）
3. 双击启动时，StatsOSD 会请求管理员权限，以读取 CPU 温度和功耗。若 Windows 显示用户帐户控制（UAC）提示，确认后即可启动。

## 托盘菜单

| 组 | 项目 |
| --- | --- |
| 快捷操作 | 显示为悬浮窗 · 显示在任务栏 · 拖动调整位置 |
| 桌面面板 | 显示指标 · 布局 · 停靠位置 · 鼠标穿透 · 强制置顶 |
| 共用外观 | 字体大小 · 字体描边 · 背景不透明度 |
| 启动与托盘 | 开机自启 · 托盘图标位置 |
| 工具 | 导出传感器 · 重启资源管理器 · 以管理员重启 |
| 退出 | 退出 StatsOSD |

设置 `%APPDATA%\StatsOSD\settings.json` ｜ 日志 `%TEMP%\statsosd.log`

右键 StatsOSD 托盘图标，可以分别勾选「显示为悬浮窗」和「显示在任务栏」。重启后会恢复两个开关各自的状态。双击托盘图标也能切换桌面 OSD。即使两块面板都关闭，仍可从托盘打开。

在「桌面面板 → 显示指标」中可连续勾选多个读数，至少保留一项。任务栏固定显示 CPU 温度、GPU 温度和内存占用率，每秒刷新，缺少读数时显示 `--`。

要自由摆放桌面 OSD，点击「拖动调整位置」，拖到目标位置后松手。「桌面面板 → 停靠位置」会用圆点标出「自由位置」，也可以在这里选回四角停靠。

任务栏面板沿用桌面 OSD 的字体、描边和硬件分组底色。在「共用外观」中调整字号、描边或背景不透明度，两处会同步生效。不透明度设为 0% 时只显示文字。

面板会避开应用按钮和通知区域。空间不足时会暂时收起，腾出空间后自动恢复。

## 技术栈与许可

C# / WPF（.NET 8）；传感器读取由 [LibreHardwareMonitor](https://github.com/LibreHardwareMonitor/LibreHardwareMonitor) 完成。
